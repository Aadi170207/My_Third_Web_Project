# My_Third_Web_Project
This is a front-end web project built using HTML, CSS, and JavaScript. It focuses on responsive design, DOM manipulation, and API integration.  The project includes an auto-sliding image carousel and a random joke feature that fetches data from a public API with smooth animations.

- Responsive layout for mobile, tablet, and desktop
- Auto-sliding image carousel with manual controls
- Random joke generator using JavaScript Fetch API
- Animated joke display for better user experience
- Clean and simple UI design
